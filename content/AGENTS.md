# Editorial conventions

Keep interface text concise. Avoid superfluous notes, instructions and explanations of standard musical terminology.

When first introducing the answer in each fugue study, explicitly identify it as tonal or real in the opening thematic description. Use the same classification in the subject/answer heading.

Use “counterpoint” as an abstract noun, not as the name of an individual theme. Name recurring accompanying themes “countersubjects”. Use “double counterpoint” or “triple counterpoint” when the relevant parts are contrapuntally invertible.
