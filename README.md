# The Well-Tempered Clavier: fugue analyses

A growing collection of analyses of Bach’s *Well-Tempered Clavier*, with interactive scores and annotated PDFs for study and performance. The project aims to cover all 48 fugues across both books.

The analyses examine subjects and countersubjects, recurring motifs, contrapuntal disposition, and formal and harmonic structure. The score can be followed continuously, with individual voices isolated in playback and passages selected for repetition.

## Sources

The BWV 891 score is based on Kroll’s Bach-Gesellschaft edition (1866), using David Huron’s digital transcription, revised by Craig Sapp. The analysis draws on Prout, Tovey and Keller; source-based observations and additional editorial readings are distinguished on the page.
